# evolution_map 仕様書

## 1. 概要

`evolution_map.txt` は、ポケモンの進化ファミリー（進化系統）を定義する辞書ファイル。
1行が1つのファミリーを表し、進化の段と分岐を記述する。O/M/L（本人/中間進化/最終進化）の展開に使われる。
複数のアプリ・ツールが共有して参照する。

- **配置場所**: `master_data/evolution_map.txt`（移行前の旧構成では `shared/`）
- **文字コード**: UTF-8
- **改行コード**: CRLF
- **参照するアプリ・ツール**: iv_strings_generator / id_generator / slim_cache_builder / data_checker

> 本書はファイル形式（何が・どう並ぶか）の正である。各アプリがこのデータをどう使うか（O/M/L の解釈など）は、各アプリの仕様書に従う。

---

## 2. フォーマット

1行が1ファミリー。1行の中で、**進化の段をカンマ `,` で区切り、同じ段の分岐をスラッシュ `/` で区切る**。

```
{1段目},{2段目},{3段目}
```

- 各段は、進化の順（進化前 → 進化後）に左から並べる。
- 段の数は 2 または 3（2段進化・3段進化）。
- ポケモン名は `pokedex_numbers.txt` に収録された名前と一致させる（表記が違うと別ポケモン扱い）。

### 区切り文字の意味

| 記号 | 意味 |
|---|---|
| `,`（カンマ） | **進化の段**の区切り。左が前段、右が次段。 |
| `/`（スラッシュ） | **同じ段の中の分岐**の区切り。1つの前段から複数へ分岐する進化先を表す。 |

---

## 3. 例

| 行 | 意味 |
|---|---|
| `フシギダネ,フシギソウ,フシギバナ` | 3段の一本道進化。 |
| `コラッタ,ラッタ` | 2段の一本道進化。 |
| `ヤドン,ヤドラン/ヤドキング` | ヤドン（1段目）から、2段目が ヤドラン または ヤドキング に分岐。 |
| `ラルトス,キルリア,サーナイト/エルレイド` | 3段目が サーナイト または エルレイド に分岐。 |
| `イーブイ,シャワーズ/サンダース/ブースター/エーフィ/ブラッキー/リーフィア/グレイシア/ニンフィア` | イーブイ（1段目）から、2段目が8種に分岐（すべて対等な進化先）。 |

---

## 4. 読み取り時の許容（各アプリ共通）

各アプリ・ツールがこのファイルを読むときは、次を許容する。データを追記・編集する際の前提としてよい。

- `#` で始まる行は**コメント**として読み飛ばす。
- **空行**は読み飛ばす。
- 各要素は前後の空白を除去（trim）してから解釈する。

> 現行の実データにはコメント行・空行は存在せず、全行が有効なファミリー定義である。上記の許容は、将来コメント等を加えても各アプリが壊れないための契約である。

---

## 5. 受け入れ条件

- 各行は、カンマで進化段を、スラッシュで同一段の分岐を区切る。
- 段の数は 2 または 3。
- 各ポケモン名は `pokedex_numbers.txt` に収録された名前と一致する。
- 進化しないポケモンは、この辞書には記載しない（各アプリは未収録を「進化なし＝本人のみ」として扱う）。
