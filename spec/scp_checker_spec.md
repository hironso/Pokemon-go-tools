# scp_checker 仕様書

## 1. 概要

ポケモンGOのPvP（トレーナーバトル）において、手持ちの個体のSCPランクとおすすめタグを計算・表示するStreamlitアプリ。

- **デプロイ先**: Streamlit Community Cloud
- **リポジトリ**: `hironso/Pokemon-go-tools`
- **メインファイル**: `scp_checker/app.py`
- **参照ファイル**: `shared/pokedex_numbers.txt`

---

## 2. 入力方法

2種類の入力方法に対応している。

### 2-1. フォーム入力（スマホ向け）

- ポケモン名をテキスト入力（日本語）
- リーグをドロップダウンで選択（S / H / M）
- シャドウチェックボックスで選択（デフォルト：オフ）
- 攻撃IV・防御IV・HP IVをテキスト入力（0〜15）
- 「追加」ボタンで追加済みリストに追加
- ポケモン名・リーグ・シャドウフラグはフォーム送信後も保持される（連続IV入力が可能）
- Tab → Tab → Tab → Enter の操作で1個体を追加できる

#### シャドウ判定ルール（フォーム入力）

シャドウチェックボックスと、ポケモン名先頭への`S`付与の2通りでシャドウを指定できる。

| 操作 | 結果 |
|---|---|
| チェックボックスオン ＋ ポケモン名`カメックス` | `Sカメックス`として追加 |
| チェックボックスオフ ＋ ポケモン名`Sカメックス` | `Sカメックス`として追加 |
| チェックボックスオン ＋ ポケモン名`Sカメックス` | `Sカメックス`として追加（二重Sにはならない） |
| チェックボックスオフ ＋ ポケモン名`カメックス` | `カメックス`（通常）として追加 |

### 2-2. ファイルアップロード（PC向け）

- `rank_cheker_input.txt`をアップロード
- テンプレートファイル（`rank_cheker_input_templete.txt`）のダウンロードボタンあり

#### rank_cheker_input.txtのフォーマット

```
# ポケモン名/リーグ(S/H/M)/攻撃IV/防御IV/HPIV
# シャドウはポケモン名の先頭にSをつける
プクリン/S/1/12/6
プクリン/S/2/14/6
Sプクリン/S/1/13/6
ラッキー/H/15/15/15
```

- リーグ：S=スーパー(1500) / H=ハイパー(2500) / M=マスター
- IV範囲：0〜15
- シャドウ：ポケモン名の先頭に`S`を付ける（例：`Sカメックス`）

---

## 3. シャドウポケモンの扱い

- ポケモン名の先頭が`S`かつ`S`を除いた名前が`pokedex_numbers.txt`に存在する場合、シャドウと判定する
- ポケモン名はすべてカタカナのため、先頭`S`は常にシャドウの識別子として機能する
- シャドウの計算ロジックは通常個体と同一（SCPランク・おすすめタグの計算式に違いなし）
- 通常個体とシャドウ個体は**別グループ**として独立してタグ判定される
  - 例：`カメックス/S`グループと`Sカメックス/S`グループはそれぞれ独立してバランス1位・2位などのタグが付与される

---

## 4. 追加済みリストの操作

- 各行に削除ボタン（✕）
- 「リストをクリア」ボタンで全削除
- **ポケモン名一括置換機能**：置換前・置換後のポケモン名を入力して「置換実行」
  - 置換後のポケモン名がpokedex未収録の場合はエラー（シャドウ名の場合はS除き名でバリデーション）
  - 置換前のポケモン名がリストに存在しない場合は警告
  - 置換後のポケモン名のシャドウフラグは名前先頭Sの有無で自動再判定される
  - 用途：計算後に間違いに気づいたときにIVを入力し直さずに修正できる

---

## 5. 計算ロジック

### 5-1. SCPランク計算

- 全4096通りのIV（0〜15の3乗）を評価
- 各IVについてレベル1.0〜51.0（0.5刻み）でCP上限以下のSCP最大を探索
- SCP降順・攻撃実数値降順でソートして順位を付与
- `scp_cache.json`は使用しない（リアルタイム計算）
- シャドウ・通常ともに計算ロジックは同一

### 5-2. おすすめタグ判定

同じポケモン×同じリーグ×同じシャドウフラグの入力個体群の中で判定する。

#### ★SCP最大
入力個体の中でSCPが最も高い個体（1体のみ）

#### ★SCP重視1位・2位
SCP1位の99%以上の中で攻撃実数値が高い順に2体
- 用途：あまり使われないポケモンで攻撃実数値も無視したくない場合

#### ★バランス1位・2位
SCP1位の98.8%以上の中で攻撃実数値最大の個体を基準に、そのSCPの99.75%以上の中で攻撃実数値が高い順に2体
- 2段階絞り込みの理由：SCPがほぼ同じ（99.75%以内）なら攻撃実数値を優先するため。SCPを犠牲にしすぎない設計。
- 用途：多用されるポケモンでミラー対面の同発を意識する場合（最もよく使うタグ）

#### ★攻撃重視1位・2位
SCP1位の98.5%以上の中で攻撃実数値最大の個体を基準に、そのSCPの99.6%以上の中で攻撃実数値が高い順に2体
- 2段階絞り込みの理由：バランスより許容範囲を広げ（99.6%）、より積極的に攻撃実数値を優先する設計。
- 用途：攻撃実数値重視の相手にも同発で勝ちたい場合

#### 設計の背景
- SCPは攻撃×防御×HPの積のため、SCP差は実戦に複合的な影響を与える
- ミラー対面では攻撃実数値が高い方がスペシャル技同時発動時に先制できる
- 98.8%・98.5%・99.75%・99.6%の数値は経験則による設定であり理論的根拠はないが、方向性は実戦理論に合致している

## 6. 出力

### 6-1. 画面表示

`st.code`で結果をテキスト表示

### 6-2. output.txtのフォーマット

```
# おすすめタグの選定条件
# ★SCP最大  : 入力個体の中でSCPが最も高い個体
# ...（各タグの説明）

                     SCPRANK  SCP  ATK    DEF    HP  CP   Level
プクリン/1/12/6      0007     1564 114.64 76.19  224 1500 29.5   ★SCP最大
プクリン/1/10/6      0108     1552 115.83 75.25  222 1497 31.0   ★SCP重視1位 ★バランス1位 ★攻撃重視1位

Sプクリン/1/13/6     0014     1559 114.20 76.05  223 1499 29.5   ★SCP最大 ★バランス1位

エンペルト/0/14/10   0014     2468 160.54 152.90 158 2497 35.5   ★SCP最大
```

- ポケモン名またはリーグまたはシャドウフラグが変わるタイミングで空行を挿入
- 通常個体とシャドウ個体は別ブロックとして出力される
- 入力表示は`ポケモン名/攻撃IV/防御IV/HPIV`形式（リーグはブロック単位で同一のため省略）
- ダウンロードボタンで`output.txt`として保存可能
