# id_generator 仕様書

## 1. 概要

ポケモン名を入力すると、進化ファミリー全員の図鑑番号をカンマ区切りで出力するStreamlitアプリ。
ポケモンGOのボックス検索で特定のポケモングループを検索するための図鑑番号リストを手軽に生成できる。

- **デプロイ先**: Streamlit Community Cloud
- **リポジトリ**: `hironso/Pokemon-go-tools`
- **メインファイル**: `id_generator/app.py`
- **参照ファイル**:
  - `shared/pokedex_numbers.txt`
  - `shared/evolution_map.txt`

---

## 2. 入力

テキストエリアに1行1ポケモン名で入力する（ファイルアップロード不要）。

```
ヒトカゲ
フシギダネ
ピカチュウ
```

- 空行・`#`始まりの行はスキップ
- ポケモン名がpokedex_numbers.txtに存在しない場合はエラー表示

---

## 3. 処理ロジック

1. 入力されたポケモン名について`evolution_map.txt`からファミリーを特定する
2. ファミリー全員の図鑑番号を`pokedex_numbers.txt`から取得する
3. 全入力ポケモン分の図鑑番号を統合して重複除去・昇順ソートする
4. カンマ区切りで1行の文字列を生成する

### 具体例

```
入力：
ヒトカゲ
フシギダネ

出力：
1,2,3,4,5,6
```

- ヒトカゲ → ヒトカゲ(4), リザード(5), リザードン(6)
- フシギダネ → フシギダネ(1), フシギソウ(2), フシギバナ(3)
- 重複除去・昇順ソート → 1,2,3,4,5,6

---

## 4. 出力

### 画面表示

`st.code`で図鑑番号リストを表示

### ダウンロード

`poke_id.txt`としてダウンロード可能

#### poke_id.txtのフォーマット

```
ポケモンID
1,2,3,4,5,6
```

## 6. 用途

- `iv_strings_generator`の出力に含まれていない特定ポケモンの図鑑番号を調べる
- ゲーム内検索バーに貼り付けて特定ポケモングループを一括検索する
