# id_generator 仕様書

> この仕様書は「何を・なぜ作るか」を定める。作りの細部（内部実装・関数分割・型の詳細）は
> 記述せず、実装（コードとテスト）を正とする。末尾の「制約」だけは、踏み越えてはならない
> 恒久的な前提として明記する。

---

## 1. 概要

ポケモン名を入力すると、進化ファミリー全員の図鑑番号をカンマ区切りで出力する Streamlit アプリ。
ポケモンGO のボックス検索で、特定のポケモングループをまとめて検索するための図鑑番号リストを手軽に生成する。

- **デプロイ先**：Streamlit Community Cloud
- **リポジトリ**：`hironso/Pokemon-go-tools`

---

## 2. 用途

- `iv_strings_generator` の出力に含まれない特定ポケモンの図鑑番号を調べる
- ゲーム内の検索バーに貼り付けて、特定のポケモングループを一括検索する

---

## 3. 入力

テキストエリアに、1行1ポケモン名で入力する（ファイルアップロードは不要）。

```
ヒトカゲ
フシギダネ
ピカチュウ
```

- 空行・`#` で始まる行はスキップする。

---

## 4. 処理

1. 入力された各ポケモン名について、進化ファミリーを特定する。
2. ファミリー全員の図鑑番号を取得する。
3. 全入力ぶんの図鑑番号を統合し、重複を除去して昇順にソートする。
4. カンマ区切りの1行の文字列を生成する。

### 具体例（ファミリーが重ならない場合）

```
入力：
ヒトカゲ
フシギダネ

出力：
1,2,3,4,5,6
```

- ヒトカゲ → ヒトカゲ(4)・リザード(5)・リザードン(6)
- フシギダネ → フシギダネ(1)・フシギソウ(2)・フシギバナ(3)
- 統合・重複除去・昇順ソート → 1,2,3,4,5,6

---

## 5. 境界ケース（利用者への応答）

### 5.1 未収録の名前があった場合

入力した名前が図鑑データに存在しなかったときは、**未収録の名前をすべて列挙してエラー表示し、図鑑番号を生成せずに処理を止める**。一部だけを処理して残りを出すことはしない（利用者が入力ミスに気づき、直してから再実行できるようにするため）。

```
例：入力に「フシギダネ」「ヒトカゲ」「ミュウツーZ」（最後が未収録）
→ 「ミュウツーZ」は図鑑データに存在しません、と表示して停止。
```

### 5.2 入力どうしのファミリーが重なった場合

複数の入力が同じファミリーを指したときは、図鑑番号を**重複させず1組にまとめる**。

```
入力：
フシギダネ
フシギバナ

出力：
1,2,3
```

（フシギダネ・フシギバナはどちらもフシギダネ(1)・フシギソウ(2)・フシギバナ(3)のファミリーを指すため、統合して1,2,3）

### 5.3 有効な入力が無い場合

テキストエリアが空、または空行と `#` コメントだけで、処理対象の名前が1つも無いときは、**警告メッセージを表示し、何も生成せずに止める**（利用者に入力を促す）。

---

## 6. 出力

### 6.1 画面表示

図鑑番号リスト（例：`1,2,3,4,5,6`）を `st.code` で表示する。

### 6.2 ダウンロード

`poke_id.txt` としてダウンロードできる。中身は次の2行。

```
ポケモンID
1,2,3,4,5,6
```

---

## 7. 制約（踏み越えてはならない恒久的な前提）

作りは実装に委ねるが、以下の3点は前提として必ず守ること。

1. **エントリポイント `id_generator/app.py` は、現在の場所・ファイル名のまま維持する。** Streamlit Community Cloud のメインファイルパスに紐づいており、動かすと公開中のアプリが壊れるため。中身は薄い UI 層とし、ロジックは `src/` を呼び出す。
2. **データファイルは `master_data/`（`pokedex_numbers.txt`・`evolution_map.txt`）を読む。**
3. **フォルダ構成は種類で分ける（`src/`・`tests/`・`spec/`）。** id_generator 固有ロジック・共通部品・データ読み込みを層として分離し、テストしやすい構造にすること。
