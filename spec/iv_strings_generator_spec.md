# iv_strings_generator 仕様書

## 1. 概要

ポケモンGOのボックス整理用検索キーワードを自動生成するStreamlitアプリ。
`iv_list_input.txt`をアップロードすると、SCPランキングをもとにバケット単位の検索式を生成して`iv_list_output.txt`として出力する。

- **デプロイ先**: Streamlit Community Cloud
- **リポジトリ**: `hironso/Pokemon-go-tools`
- **メインファイル**: `iv_strings_generator/app.py`
- **参照ファイル**:
  - `shared/pokedex_numbers.txt`
  - `shared/evolution_map.txt`
  - `shared/slim_cache.json`
  - `shared/iv_list_input_templete.txt`（テンプレート）

---

## 2. 入力ファイル（iv_list_input.txt）

### フォーマット

```
# ポケモン名/リーグ/TopN/対象指定
フシギダネ/S,H/200/L
ピカチュウ/S/300/L
リオル/S,H/1000/L
ベロリンガ/S/200/O
サイホーン/S/200/M
```

### 各項目の説明

| 項目 | 内容 |
|---|---|
| ポケモン名 | 日本語ポケモン名（pokedex_numbers.txtに収録されている名前） |
| リーグ | S（スーパー1500）/ H（ハイパー2500）/ M（マスター）、複数可（S,H） |
| TopN | SCPランキング上位何件を対象とするか（1〜4096） |
| 対象指定 | O=本人 / M=中間進化 / L=最終進化、複数可（L,M） |

### 対象指定（O/M/L）の展開ルール

- `L`：evolution_map.txtのファミリー最終進化形
- `M`：ファミリーが3段階以上の場合は2番目、2段階の場合は最終進化形
- `O`：入力したポケモン本人
- 進化しないポケモン（evolution_map.txtに未収録）はO指定を使用

---

## 3. バケット定義

ゲーム内の検索はIVを5段階のバケットで指定する。

| バケット | IV範囲 | 検索文字列 |
|---|---|---|
| 0 | 0 | 0こうげき / 0ぼうぎょ / 0HP |
| 1 | 1〜5 | 1こうげき / 1ぼうぎょ / 1HP |
| 2 | 6〜10 | 2こうげき / 2ぼうぎょ / 2HP |
| 3 | 11〜14 | 3こうげき / 3ぼうぎょ / 3HP |
| 4 | 15 | 4こうげき / 4ぼうぎょ / 4HP |

## 4. slim_cache.json

### 概要

`slim_cache_builder.py`（toolsフォルダ）をローカルPCで実行して生成するキャッシュファイル。
`scp_cache.json`（704MB）の代替として必要なデータのみを抽出した軽量版（約4MB）。

### 格納データ

- iv_list_input.txtで参照されるポケモン×リーグの組み合わせのみ
- 各エントリ：`rank,atk_bucket,def_bucket,hp_bucket,atk_real`（TopN件）

### 更新が必要なタイミング

- pokedex_numbers.txtに新ポケモンを追加したとき
- iv_list_input.txtに新しいポケモン・リーグを追加したとき

---

## 5. バケット選抜ロジック

TopN件のランキングデータから採用するバケットを決定する。

### 全体10%ルール
TopN件全体で出現率10%以上のバケットを採用

### 上位30%10%ルール
TopN件の上位30%の中で出現率10%以上のバケットを採用

### SCP70拡張＋攻撃実数値強化
SCP上位70位以内の個体の中で攻撃実数値トップ20件のバケットを強制採用

### フォールバック
上記いずれでも採用なしの場合、出現したバケットを全採用

---

## 6. グループ分け

### グループパターン

23種類のパターン（攻撃・防御・HPのバケット組み合わせ）を定義。
厳しい条件（パターン1）から緩い条件（パターン23）の順に割り当てる。

### 閾値

- **グループ1〜21**：候補ユニットが**15以上**の場合にグループ化
- **グループ22〜23**：候補ユニットが**5以上**の場合にグループ化

### 個別枠

どのグループにも入らなかったユニットは個別枠として出力する。

## 7. 出力（iv_list_output.txt）

### 固定文字列

| 用途 | 固定フィルター |
|---|---|
| GBL用・レイド用 | `&!お気に入り&!#&!しゃどう&!だいまっくす&!きょだいまっくす` |
| 確認用 | `&お気に入り,#&!しゃどう&!だいまっくす&!きょだいまっくす` |
| トレードタグ除外 | `&!#交換&!#内交換&!#100km&!#300km` |
| 博士送り用 | `&!お気に入り&!#&!しゃどう&!色違い&!だいまっくす&!きょだいまっくす` |

### 出力ブロック構成（グループごと）

各グループにつき以下の5種類の検索式を出力する：
1. GBL用
2. レイド用
3. 確認用
4. 最終確認用
5. 博士送り用

### 個別枠の出力

- 個別枠-GBL用（まとめて検索）
- 個別枠-レイド用
- 個別枠-確認用
- 個別枠-最終確認用
- 個別枠-博士送り用

※個別の検索式（1行ずつ）は出力しない

### 末尾固定ブロック

- 100%個体
- 0%個体
- 最後の確認用
- 伝説・幻・ウルトラビースト
- ダイマックス・キョダイマックス
- 色違い
