# pokedex_numbers 仕様書

## 1. 概要

`pokedex_numbers.txt` は、ポケモンの図鑑番号と種族値を定義する辞書ファイル。
複数のアプリ・ツールが共有して参照する、リポジトリの基礎データの1つである。

- **配置場所**: `master_data/pokedex_numbers.txt`（移行前の旧構成では `shared/`）
- **文字コード**: UTF-8
- **改行コード**: CRLF
- **参照するアプリ・ツール**: scp_checker / iv_strings_generator / id_generator / slim_cache_builder / data_checker

> 本書はファイル形式（何が・どう並ぶか）の正である。各アプリがこのデータをどう使うかは、各アプリの仕様書に従う。

---

## 2. フォーマット

1行が1ポケモンを表す、タブ区切り（TSV）5列のテキストファイル。

```
{ポケモン名}\t{図鑑番号}\t{HP種族値}\t{こうげき種族値}\t{ぼうぎょ種族値}
```

### 列の定義

| 列 | 内容 | 型 |
|---|---|---|
| 1 | ポケモン名 | 文字列（日本語） |
| 2 | 図鑑番号 | 整数 |
| 3 | HP種族値 | 整数 |
| 4 | こうげき種族値 | 整数 |
| 5 | ぼうぎょ種族値 | 整数 |

### 例

```
ハピナス	242	496	129	169
フシギバナ	3	190	198	189
```

（表記上はスペースに見えるが、列区切りは半角スペースではなくタブである。）

---

## 3. ポケモン名の規則

- ポケモン名は、他ファイル（`evolution_map.txt`・`iv_list_input.txt` など）や各アプリの入力で参照される**キー**である。表記が1文字でも異なると別のポケモンとして扱われる。
- フォーム違い・リージョンフォームは、括弧付きで区別する。
  - 例: `ジガルデ(パーフェクトフォルム)`・`ディアルガ(オリジンフォルム)`・`アローラロコン`
- 性別記号など、ゲーム表記に含まれる記号もそのまま名前の一部とする。
  - 例: `ニドラン♀`・`ニドラン♂`

---

## 4. 読み取り時の許容（各アプリ共通）

各アプリ・ツールがこのファイルを読むときは、次を許容する。データを追記・編集する際の前提としてよい。

- `#` で始まる行は**コメント**として読み飛ばす。
- **空行**は読み飛ばす。
- 各行は前後の空白を除去（trim）してから解釈する。
- 列が5つに満たない行、図鑑番号・種族値が整数に変換できない行は、**その行を無視**する（エラーで停止はしない）。

> 現行の実データにはコメント行・空行・不正行は存在せず、全行が正しい5列である。上記の許容は、将来コメントや区切りを加えても各アプリが壊れないための契約である。

---

## 5. 受け入れ条件

- 各データ行はタブ区切りで、上記5列をこの順に持つ。
- ポケモン名は一意（同名の重複行を作らない）。
- 図鑑番号・種族値はいずれも整数。
- コメント行・空行を混在させても、各アプリが正しく読み飛ばせる。
